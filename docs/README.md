## Estados dos registros

| Estado | Significado |
| --- | --- |
| Confirmado | Diretriz explicitamente definida nos materiais da equipe. |
| Proposto | Detalhamento inicial que ainda depende de revisão. |
| A validar | Informação ausente ou escolha ainda não realizada. |
| Aprovado | Equipe registrou data, responsáveis e decisão. |

Manter os IDs ao revisar. Registrar mudanças de escopo na issue e atualizar requisito, regra, história, modelo, teste e card afetados.
