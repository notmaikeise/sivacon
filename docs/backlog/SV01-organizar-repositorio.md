# [SV01] Organizar o repositório e o Project compartilhados

## Campos da issue e do Project

| Campo | Valor sugerido |
| --- | --- |
| Status inicial | Backlog |
| Prioridade | P0 |
| Etapa | E0 |
| Frente | Gestão |
| Escopo | MVP |
| Assignee | Definir com a equipe. |
| Labels | `tipo:planejamento`, `tipo:documentacao`, `area:gestao` |

## Objetivo

Disponibilizar uma base única de trabalho para a equipe.

## Rastreabilidade

C01-C03; RNF03

## Entregas

- [ ] Criar o repositório, adicionar o kit e revisar os documentos iniciais.
- [ ] Conceder acesso ao repositório e ao Project aos integrantes confirmados.
- [ ] Configurar campos, labels, vistas e fluxo de issues/PRs.

## Critérios de aceite

- [ ] README e índice acessíveis, com links funcionando.
- [ ] Equipe consegue acessar código, issues e quadro com as permissões combinadas.
- [ ] Cards iniciais são issues do repositório vinculadas ao Project.
- [ ] Condições de licença/publicação ficam registradas como pendentes ou decididas.

## Dependências

Nenhuma.

Os IDs SV são referências do planejamento. Após criar as issues, registrar os números/links reais nesta seção.

## Evidência de conclusão

URL do repositório, URL do Project, PR inicial e conferência de acesso por um integrante.
