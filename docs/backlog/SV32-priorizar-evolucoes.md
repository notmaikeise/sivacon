## Objetivo

Selecionar extras por necessidade, prazo e impacto, sem expandir o MVP retroativamente.

## Rastreabilidade

RF12; evoluções de favoritos, comparação e reserva

## Entregas

- [ ] Avaliar reserva, favoritos, comparação, pós-venda, comissões e indicadores.
- [ ] Revisar atores, regras, dados e riscos de cada opção.
- [ ] Criar novas issues pequenas para as evoluções aprovadas.

## Critérios de aceite

- [ ] Equipe seleciona escopo de evolução e justifica prioridades.
- [ ] Cada funcionalidade selecionada recebe critérios e dependências.
- [ ] Políticas de reserva/comissão não são inventadas neste card.
- [ ] Integrações bancárias reais, se desejadas, recebem planejamento separado.

## Dependências

SV28

Os IDs SV são referências do planejamento. Após criar as issues, registrar os números/links reais nesta seção.

## Evidência de conclusão
