# Visão e escopo

## Produto

O SIVACon organiza a venda de veículos do primeiro contato ao fechamento. Conecta site público, área do comprador e CRM interno. A concessionária é o cliente contratante; visitantes, compradores e funcionários são usuários. A professora avalia o trabalho acadêmico e não assume automaticamente o papel de cliente comercial.

## Situação das definições

| Estado | Definição |
| --- | --- |
| Confirmado | Projeto acadêmico, primeiro cenário fictício de motos, três áreas conectadas e base adaptável a concessionárias. |
| Confirmado | Hospedagem final local, com equipamentos disponíveis e sem contratar infraestrutura ou API paga. |
| Preferência técnica | Java no backend e React/HTML/CSS no frontend, aproveitando as competências informadas. |
| Proposto | MVP por jornada, processo incremental e iterativo, backend modular, PostgreSQL e isolamento por instalação. |
| A validar | Integrantes, prazo, rubrica, políticas comerciais, hardware e acesso localhost ou LAN. |

## MVP proposto

| Área | Entregas |
| --- | --- |
| Vitrine | Página inicial, catálogo com filtros, detalhes e interesse. |
| Comprador | Cadastro/login, atendimentos, propostas, simulações e andamento. |
| CRM | Estoque, compradores, funil, histórico, propostas, aprovações e venda fictícia. |
| Administração | Usuários/perfis, configuração da loja e resumo básico de vendas. |
| Operação | Instalação local, dados persistentes, manual e restauração de backup. |

Jornada de demonstração: **estoque e vitrine → interesse → atendimento → proposta e simulação → aprovação → venda fictícia**.

## Evoluções

Busca inteligente começando por regras; segunda instalação fictícia; reservas, favoritos e comparação; entrega e pós-venda detalhados; comissões e relatórios avançados. Pagamentos bancários reais e análise externa de crédito exigem novo escopo.

O nome “Inteligente” expressa a visão de evolução do produto. Um agente de IA não é requisito para a primeira demonstração.

## Limites da primeira versão

Uma loja fictícia e uma unidade de veículo por proposta. Dados, crédito e pagamentos de demonstração serão simulados. A vitrine dispensa login, mas permanece acessível apenas no ambiente local aprovado.
